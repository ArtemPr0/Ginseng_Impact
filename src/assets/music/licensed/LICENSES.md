# Licensed tracks

Every media file in this folder needs one line here, or the build fails (`scripts/music-audit.mjs`). One line per
track, four fields separated by ` — ` (an em dash with a space either side):

```
<file name> — <licence> — <source url> — <credit line>
```

The file name is the file's name in this folder (`kingdom.ogg`), the licence is the exact grant that covers use in a
game (`CC BY 4.0`, `own work`, `written permission from <rights holder>, <date>`), the source url is where the track
and its licence can be checked, and the credit line is the attribution the licence asks for.

Only tracks licensed for use in the game go here: your own music, game-licensed tracks, or ones the rights holders
permitted. A store purchase or a streaming download is a licence to listen, not to put the recording in a game.
